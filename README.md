# Firearms

A custom ProjectKorra addon ability that replaces Fission with a rapid-fire, lightning-infused FireBending stance.

## Overview

Firearms is a stance-style ability. When you sneak, you ignite blazing armaments for a limited time, unlocking extra fire and lightning techniques plus mobility options. If you would take fall damage during the stance, fiery arms flare beneath you to break the impact.

## How It Works

**Activation**: Sneak to enter Firearms (45 seconds)

While active:
- **Left Click**: Fire Volley (damage)
- **Right Click**: Lightning Arc (damage + chain)
- **Sneak + Left Click**: Cinder Lift (vertical mobility)
- **Sneak + Right Click**: Blaze Dash (forward mobility)
- **Fall Protection**: Cancels fall damage with a fiery burst

## Features

- **Stance Duration & Cooldown**: 45s duration, 20s cooldown by default
- **Multiple Sub-Abilities**: Damage and mobility options while active
- **Lightning Chains**: Arc lightning to nearby targets
- **Display Entities**: Fiery arm displays for enhanced visuals
- **Configurable Settings**: All values can be tuned via config

## Configuration

Settings live under `ExtraAbilities.ShadowTP.Firearms` and include duration, cooldown, volley stats, lightning stats, mobility stats, and fall-save timing.
